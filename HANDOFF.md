Read `CLAUDE.md` first (goals, stack, content rules, working style). This file is the current status.

The app is called **Azulejo** (user chose it 28 October 2026, after the tile you earn on the Home tile wall). The name is in `index.html`, the sidebar, `package.json` and the backup file name (`azulejo-backup-<date>.json`; older `portugues-backup-…` files still restore). ## Done (on `main`)
Everything up to the Slang quiz is pushed to GitHub (26 October 2026). Ask the user before each push; they run it from their Terminal panel.

- **App shell:** React + Vite, dark green theme (colours are variables at the top of `src/styles.css`), sidebar that becomes a bottom bar on phones, dashboard with phrase of the day, streak, progress panel, backup/restore of progress as a JSON file. No leaderboard (user doesn't want one).
- **Speech out:** `src/lib/speech.js` only speaks with a Portuguese voice (prefers pt-PT), never an English one. `speak(text, { rate })` supports a slower rate.
- **Vocab (complete for Level 1):**
  - Content: `src/data/levels.json` (levels, units, `passMark` 0.8) and `src/data/vocab/level-1.json` (55 items in 5 topic units, words and phrases, all `verified: false`). Nouns are stored without the article plus `gender`; `displayPt()` adds o/a. `alternatives` lists other accepted answers; `blank` is the gap word in the example sentence.
  - Casual pt-PT is the default (*desculpa*, *como estás?*); the polite form is in `alternatives` or the note. Polite forms stay where they're natural (waiter, strangers).
  - Each unit: Flashcards (spaced repetition, `src/lib/srs.js`), Multiple choice (Portuguese to English, English to Portuguese, fill the gap), Type it (from English). Wrong answers return at the end of a session; green tick / red cross feedback.
  - Marking (`src/lib/answers.js`): ignores capitals, punctuation and missing accents (shows the right spelling), nouns with or without article; anything else only if listed in `alternatives`. Never guesses.
  - **Level 2** ("Everyday life", added 27 October 2026): `src/data/vocab/level-2.json`, 54 items in 5 units (restaurant, shopping, asking the way, home and routine, days and plans), more phrases than Level 1. All `verified: false`.
  - **Levels 3–6** (added 28 October 2026, one file each in `src/data/vocab/`): 3 "Getting by" (work, health, weather, clothes, describing people), 4 "Out and about" (travel, hotel, food shopping, free time, feelings), 5 "Getting things done" (phone, bank and post office, renting and repairs, appointments, complaints), 6 "Opinions and the news" (opinions, agreeing, telling a story, news, nature). 221 items, all `verified: false`. Plural-only nouns (calças, férias, correios…) have no `gender`, so no wrong o/a is added. Every item was typed through in the browser and marked right.
  - **Levels 7–17** (added 27–28 October 2026, chosen by how common the words are, not by topic): 7 "Core verbs", 8 "Describing and linking", 9 "Everyday essentials" (common nouns, places, time words, question words), 10 "Body and feelings", 11 "Numbers, colours and dates", 12 "More verbs", 13 "Home and things", 14 "Food and drink", 15 "Town and society", 16 "Life and describing" (incl. *ter pressa*, *dar jeito*, *fazer falta*), 17 "Everyday conversation" (70 items: reactions, linking words like *aliás*/*afinal*/*no entanto*, time expressions, asking for help, saying how things went). 60 items each (Level 17: 70), 12 per unit (17: 14), including a few 3+ word phrases so each level has a word-order round. Verbs are stored as the infinitive (reflexives as *lembrar-se*, with the plain verb accepted); adjectives list the feminine in `alternatives`. All typed through in the browser and marked right; word order played through. All `verified: false`. **Vocab now has 1,000 items: the agreed target is reached.** B1 is roughly 2,000+ words, so say so if asked. Levels 10–17 were written from a compact list by a helper script (not in the repo); the JSON files are the source of truth.
  - **Word order** (per level, `src/pages/vocab/WordOrderSession.jsx`): tap word tiles to build every phrase of 3+ words in the level. Only fixed phrases are used, so one order is right; any other natural order must be listed in `alternatives` (done for the "por favor" / "obrigado" / time-first variants). Best score saved per level in `vocab.order`. It doesn't touch spaced repetition. Also used in the middle part of the level test.
  - Level test: 20 questions getting harder (choice, typed gap, typing), marked at the end (silent on purpose, user agreed). 80% passes and opens the next level permanently. Retake any time. From Level 2 on, a quarter of questions come from earlier levels.
- **Reading** (aim agreed 29 October 2026: B1 reading, 2 texts per Vocab level, built in batches of 4 levels so the native speaker can keep up). One file per level in `src/data/reading/` (`level-1.json` … `level-9.json` so far; import new ones in `src/lib/reading.js`). Texts open with their Vocab level and the Reading page is grouped by level. Every word has a meaning in the text's own `glossary`, so meanings fit the context. Questions: multiple choice (`options` + `answer` index) or true/false (`"type": "tf"`, `"answer": true/false`, always shown True then False); each can have a `why`, an exact quote from the text shown after checking. Before committing, check in the browser: no word without a meaning, no unused glossary entry, every `why` found in the text, every answer valid. All `verified: false`.
  - **Batch 1 done (29 October 2026), Levels 2–5:** message about a birthday dinner, a daily routine, at the health centre, weekend weather forecast, postcard from Lagos, at the market, building notice (water cut), complaint email. 81–99 words each, 5 questions each.

- **Speaking (built, switched off):** listen, speak into the mic, see which words the browser's recogniser picked up (`src/lib/recognition.js`). - **Grammar:** grouped into stages (`src/lib/grammar.js` lists one JSON file per stage; topics are numbered straight through). Stage "Building blocks" (`basics.json`, 4 topics: gender and plurals, contractions do/na/ao/pelo, possessives, este/esse/aquele) uses `"focus": "word"` so practice says "missing word" and each drill gives its own `hint`; tables can set `listen` ("form" or "both") and `caption`. Later stages, in order: "Have done, had done" (`perfect.json`: tenho feito, tinha feito), "Subjunctive" (`subjunctive.json`: present forms, when to use, imperfect, future, choosing), "Personal infinitive" (`infinitive.json`), "Linking words" (`linking.json`: por/para, que/quem/onde/o que, porque/por isso/embora). Stage "Future and \"would\"" (`future.json`, 4 topics: future tense, conditional, será que / guessing, mesoclisis for recognition). Stage "Commands" (`commands.json`, 3 topics: tu do/don't, polite and vocês, commands with pronouns). Stage "Pronouns" (`pronouns.json`, 4 topics: after the verb, in front after não/question words/que/já, lhe/lhes, lo/la/no/na) adds an `order` drill: word tiles from `answer` (hyphenated pronouns become their own tile, first word lowercased), marked ignoring hyphens, other natural orders in `alternatives`. Stage "Past tense" (`past.json`, 5 perfeito topics: -ar, -er/-ir, fui/tive/estive, fiz/disse/vi/dei, vim/pus/pude/quis; then `imperfect.json`, 4 imperfeito topics: regular, era/tinha/estava/ia, perfeito vs imperfeito, estava a + polite queria/podia/gostava) adds a `rewrite` drill: shows `from` (a present sentence, labelled "Now:") and asks for the past form in the gap. Stage "Everyday patterns" (`patterns.json`, 4 topics: reflexive verbs, estar a + verb, verb + verb patterns such as tenho de / costumo / preciso de, ficar). Stage "Present tense" (`present.json`), 15 topics: ser, estar, ser or estar?, ter, ir, regular -ar/-er/-ir, fazer, poder, querer, then irregular groups (ver/dar/ler, dizer/trazer/saber, vir/pôr, pedir/ouvir/dormir/sair). Topics with several verbs use `tables` (one per verb, with meaning) instead of `table`; each drill names its verb with a `verb` field and can list accepted spellings in `alternatives` (e.g. oiço, lêem). Each topic: explanation, verb table with Listen, examples, pt-PT notes, then practice (type the form, type the verb in a sentence, pick ser/estar with a reason). Every drill is written by hand in the data; nothing is generated. No vós; você included with a note on how it sounds in Portugal. All `verified: false`.
- **Menu:** 7 items (Home, Vocab, Speaking, Reading, Grammar, Slang, Tutor); the user chose to keep Speaking visible while it's switched off.

- **Weak / Secure / Mastered** (user request 27 October 2026: "you can't have learnt everything in one go"). Rules in `src/lib/mastery.js`, shown with `src/components/Stages.jsx` (stage bar for vocab, coloured tag elsewhere; colours `--weak/--secure/--mastered`).
  - Vocab words: from the flashcard interval. Under 7 days = weak, 7+ = secure, 21+ = mastered. Typing right in one session only makes a word weak; it takes real days to move up. "I already know this" now makes a word secure (7 days), not mastered.
  - Grammar topics, reading texts, slang quiz: records keep `last`, `lastDate` and `passes` (days scored 80%+). Last score under 80% = weak; 80%+ = secure; 80%+ on 3 different days spanning a week = mastered. Old `{best, total}` records count their best as the last score.
  - Home "Carry on" suggests a weak grammar topic, or a secure one not practised for a week. Home area tiles show only a colour bar (no numbers, user request 28 October 2026) with one colour key under them; the "words learned" stat was removed. Tile wall: a tile per vocab unit or grammar topic once it is secure.

- **AI tutor** (added 28 October 2026, idea taken from the DeutschLab app): menu item "Tutor" (`src/pages/tutor/Tutor.jsx`, `src/lib/ai.js`). No paid API and no server: the learner pastes their own **free Google Gemini API key** (from aistudio.google.com/apikey). The browser checks it by listing models, picks the newest free Flash model (Lite first, never Pro or preview) and talks to Gemini directly. The key is kept in `localStorage` (`pt-app-ai-key`) only, not in the progress backup, and is sent only to Google in a header. Pick a situation (free chat, meeting someone, café, weekend, asking the way), chat in pt-PT; each reply has Listen and an English toggle, and the learner's messages get corrections (wrong / right / why). The prompt enforces pt-PT and sends the words from open vocab levels plus the grammar topics practised, so it stays at the learner's level. Safeguards: 20 requests a day, 15 messages per conversation, last 12 messages sent. Conversations are not saved. Labelled as AI help not checked by a native speaker. Tested only with faked Google replies; **not yet tried with a real key**.
  - Fine while the app runs on the user's own computer. If the app goes online for other people, each person still brings their own key; never put a key in the code.
